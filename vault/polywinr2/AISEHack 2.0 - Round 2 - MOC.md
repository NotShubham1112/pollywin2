## 🎯 Quick Facts

- **Task:** Predict **7 polymer properties** from [[SMILES]] strings
- **Training data:** 7,409 polymer property measurements (see [[Dataset Files]])
- **Test data:** 4,497 data points (see [[Dataset Files]])
- **Extra data:** [[PI1M.csv]] — extra polymer SMILES for advanced algorithms
- **Winners decided by:** [[Leaderboard and Evaluation|Private Leaderboard]] on hidden test set
- **Baseline:** [[Baseline Model|RDKit + Ridge Regression]]
