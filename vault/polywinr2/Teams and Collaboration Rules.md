# Teams and Collaboration Rules

Part of: [[AISEHack 2.0 - Round 2 - MOC]] · Source: Rules §5–§6

---

## Team Rules

- You may join or form **only one Team** (if the competition website permits teams).
- Each Team member must be a **single individual with a separate Kaggle account**.
- You must **register individually first**, then confirm Team membership via the Kaggle notification.
- Team size may not exceed the **Maximum Team Size** stated on the competition website.

## Team Merger

Allowed only if:
1. Combined Team ≤ Maximum Team Size
2. Combined Submissions don't exceed what one Team could have made by that date
3. Merger completes **before** any merger deadline or the competition deadline
4. Combined Team meets all other rules

## Private Sharing

> ❌ **No private sharing of code or data outside of Teams.**
Sharing code publicly (forums/notebooks) is fine — see below.

## Public Code Sharing

- Competition Code may be shared **publicly on Kaggle.com** (discussion forum or competition notebooks) for the benefit of all competitors.
- Publicly shared code is deemed licensed under an **OSI-approved open source license** that does not limit commercial use.
- Don't violate third-party IP rights when sharing.

## Open Source Usage

Open source code used to generate a [[Submission Rules|Submission]] must be under an **Open Source Initiative-approved license** that in no event limits commercial use of the code or model.

This matters when picking libraries for featurization (e.g. RDKit — see [[Baseline Model]]) and modeling.

Violations → [[Disqualification and Conduct]]
