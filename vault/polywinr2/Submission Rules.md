# Submission Rules

Part of: [[AISEHack 2.0 - Round 2 - MOC]] · Source: Rules §3–§6 · Data format: [[Dataset Files]]

---

## Entry Requirements

- **No purchase necessary** to enter or win.
- Register on the Competition Website **before the Entry Deadline**.
- Submissions must follow the format/Requirements stated on the competition website (see `sample_submission.csv` in [[Dataset Files]]).
- Submissions must arrive **before stated deadlines** — late submissions are not Prize eligible.

## Competition Period

- Runs Start Date → Final Submission Deadline.
- Timeline **subject to change** — sponsor may add hurdle deadlines.
- ⚠️ **You are responsible for checking the competition website for changes and converting time zones.**

## No Hand Labeling

> ❌ Submissions may **not** use or incorporate information from **hand labeling or human prediction** of validation dataset or test data records.

## Multi-Stage Rule

If stages have temporally separate train/test data, one or more valid Submissions may be required **during each stage** to remain Prize eligible.

## Void Submissions

A Submission is void if it is in whole or part: illegible, incomplete, damaged, altered, counterfeit, obtained through fraud, or **late**.

## Daily Limits

Only up to the **maximum number of Submissions per day** specified on the competition website.

## Final Submission

The "Final Submission" is the one you select (or Kaggle auto-selects) for final placement on the [[Leaderboard and Evaluation|Private Leaderboard]].

## Code Requirements

See [[Teams and Collaboration Rules#Public Code Sharing]] — no private cross-team sharing; public sharing under OSI-approved license on Kaggle.

## Notebook-Backed Submissions (Round 2)

> ⚠️ Round 2 is **notebook/code-only**. Every submission must be generated inside a Kaggle Notebook; **prediction-only CSV uploads that aren't backed by a compliant notebook are invalidated**. See [[Notebook Submission Requirement]] for the full rule (§6.2.2, §7.1, §7.2) and the exact host-sharing/pinning/reproducibility obligations.
