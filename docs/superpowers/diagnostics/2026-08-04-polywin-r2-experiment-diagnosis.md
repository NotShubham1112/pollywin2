## 1. Evaluation metric (exact definition)

The score is the **mean coefficient of determination (R²)** across 7 targets:

$$\text{Score} = \frac{R^2_{\text{Tg}} + R^2_{\text{Egc}} + R^2_{\text{Egb}} + R^2_{\text{Ei}} + R^2_{\text{Eea}} + R^2_{\text{Nc}} + R^2_{\text{EPS}}}{7}$$

with, per target,

$$R^2 = 1 - \frac{\sum_i (y_i - \hat y_i)^2}{\sum_i (y_i - \bar y)^2} = 1 - \frac{\text{RMSE}^2}{\sigma_y^2}$$

> Equivalently `R² = 1 − (RMSE/σ)²`, i.e. the metric is the mean standardized R² and is **fully determined by RMSE scaled by the target's variance.**
> Note: this means targets are weighted **7 ways equal** regardless of sample size — a weak R² on a sparse target (e.g. eps) hurts exactly as much as a weak R² on a dense one (tg).

**Leaderboard mechanics (critical):** The public board is computed on **≈37% of the test set**; the final standings use the **other 63%**. So the public LB is a partial, noisy snapshot.

We validate our interpretation: the v6 stack's mean R² computed from **honest train-sigma proxy** (0.8449) matches its public LB (0.847) closely, confirming train σ is a good proxy for the evaluation σ.

## 2. Architecture summary

9-layer pipeline, generated by `build_pipeline_nb.py`:
1. **Canonicalization** — SMILES canonicalisation, dedupe, group-key for fold-safe CV.
2. **Feature factory** — RDKit descriptors + Morgan/MACCS/AtomPair/Topological fingerprints + polymer-physics scores. 3325 model columns after const-drop.
3. **Retrieval memory** — fold-safe kNN over 3 neighbour pools (global / same-target / cross-target priors) → 57 retrieval columns (once active).
4. **Target-aware GBM experts** — LightGBM / CatBoost / XGBoost / HistGB per target (10-fold GroupKFold OOF).
5. **Electronic Foundation Network (FFN)** — archived behind `RUN_NNS` (OFF in all submitted runs).
6. **Tg isolation (Tg NN)** — archived behind `RUN_NNS` (OFF).
7. **Stacking** — Ridge level-1.5 + level-2 meta on OOF predictions.
8. **PI1M pseudo-labelling** — confidence-filtered (cross-model disagreement), capped integration, retrain experts (v8 only).
9. **Submission + figures.**

**Submitted configs:**
- v4/v6: base 3325-col model set (no retrieval, no pseudo, no NNs) — 4 GBM families + Ridge L1.5 + L2 meta.
- v7: retrieval ON (FULL = BASE + 57 retrieval cols). **Not submitted** (failed honest OOF).
- v8: BASE config + PI1M pseudo-labelling (10-fold, 2× cap). Submitted.

**D. Public LB: 0.828 (−0.019 vs v6 0.847).**
- **Verdict: FAILURE — pseudo gains did not transfer to the 37% public test.**
- Despite 7/7 honest-OOF wins, the augmented models scored *worse* than the untouched v6 stack.

**Primary post-mortem (pseudo-label optimism):**
1. The augmented GBMs learned from their **own confident predictions** (train-distribution polymers); OOF improves because those points are in-distribution, but the hidden test polymers fall outside that coverage.
2. **2× cap is aggressive**, especially on the sparse targets (eps/ei/nc/eea doubled) → over-weights model-generated noise that does not generalise.
3. Stack soft spots: `final` degrades ei (0.4677) and eps (0.5431) vs the LGB arm (0.4467 / 0.5390).
4. Submission cell uses a sequential-overwrite fallback and emitted test predictions from the **augmented best-base model** (`test_store[k]`), not the meta-stack.

- **Leaderboard top: 0.916** (Sandman); ~6 teams in 0.90–0.916.
- **Our anchor: 0.847 ≈ rank 44–45**.
- **v8 (0.828) is not competitive; v6 (0.847) is the anchor.**

## 7. What worked vs what failed (transferable lessons)

| Change | OOF effect | Public LB effect | Verdict |
|---|---|---|---|
| v4 → v6 honest stack | better | 0.828 → 0.847 (+0.019) | ✅ real gain |
| v7 retrieval cols | FULL − BASE all + | not submitted | ❌ failed (fold-overfit) |
| v8 pseudo (2× cap) | 7/7 OOF wins (+0.017 R²) | **0.847 → 0.828 (−0.019)** | ❌ pseudo overfit |
| L2 meta (`final`) | < L1.5 (`l15`) | — | ⚠️ detracts, revisit |

**Core lesson:** OOF mean‑R² is **not** a reliable proxy for the public LB when the model learns from self-generated pseudo-targets; only the real public test (or a distribution-shifted holdout) reveals generalisation.

## 8. Recommended next steps (design handoff)

1. **Anchor = v6 stack (0.847).** Never regress below it.
2. **v9 priority: add a GNN OOF arm** (e.g., MPNN/GIN/GAT over the polymer graph) as an extra base model blended into L1.5/L2 — biggest lever for eps/ei/nc/eea.
3. **Fix stacking & submission**: use L1.5 (or a well-behaved meta) instead of the current overwrite-bugged cell; ensure `final ≥ l15`.
4. **Pseudo-labelling**, if reused: cap **≤1.25×**, apply **only to dense targets (tg/egc)**, never the sparse ones; consider weighting/down-weighting pseudo rows; validate generalisation on a shifted holdout before trusting OOF.
5. **eps** (worst, R² 0.728) merits its own treatment: dedicated chemistry features + per-target tuned model + any external data.
