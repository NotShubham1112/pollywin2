# Reproduce v11 → v13 — Notebook-Backed Submission Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a **compliant, reproducible, notebook-backed submission** for Round 2 (rules §6.2.2, §7.1, §7.2 — see [[Notebook Submission Requirement]]). Sequence: first a notebook that **reproduces the v11 blend (0.852 LB) end-to-end from official data inside one Kaggle run** (protects our current best score from invalidation), then **iterate v13 (small-five specialist)** on top of the same notebook.

**Why:** Our standing v11 blend (0.852) was produced locally (`gnn_moe_blend.py`) and submitted as a prediction-only CSV with no notebook link → invalidatable under §6.2.2. Every final submission must be (a) generated entirely inside a Kaggle notebook, (b) pinned to the exact producing version, (c) shared (view) with the 5 hosts, (d) linked in the submission description, and (e) reproducible by the hosts post-competition.

**Compliance checklist (mandatory, from §6.2/§7):**

- [ ] Output file named exactly **`submission.csv`** in `/kaggle/working`.
- [ ] **Pinned/default notebook version == the version that produced the submitted score** (do not overwrite default after submission).

- [ ] Runs within Kaggle compute/time limits (GPU 9h / CPU 12h), no manual intervention.
- [ ] Local scripts/caches used **only** for offline analysis + `POLYWIN_SMOKE=1` smoke runs — never for the submission itself.

**Tech stack:** Python, RDKit, pandas/numpy, LightGBM/CatBoost/XGBoost/HistGB, scikit-learn, PyTorch + PyTorch Geometric, matplotlib/seaborn, nbformat. No new dependencies.

## Phase 0 — Reproduce v11 blend in-notebook (protect the score)

The v12 notebook (`build_v12_kaggle_nb.py`) already contains, verbatim, the v11 blend machinery: GBM stack (4 GBMs + L1.5 Ridge + L2 meta), v10 GINE pretrain-on-PI1M + fold-safe fine-tune, and the **fold-safe per-target weight blend** (`v11_blend_oof`/`V11_W`). Phase 0 re-uses that pipeline as-is to emit a compliant submission equal to v11 (0.852).

- [ ] **Notebook:** `PolyWin_R2_v11_reproduce.ipynb` (generated by `build_v12_kaggle_nb.py` with the v11-blend fallback path, or a thin `build_v11_reproduce_nb.py` wrapper). Self-contained: no local caches on Kaggle (`USE_GBM_CACHE`/`USE_GNN_CACHE` = False on `/kaggle`).
- [ ] **Smoke:** `POLYWIN_SMOKE=1` locally on cached experts → pipeline completes end-to-end, submission written, physics bounds applied.
- [ ] **Kaggle full run:** confirm the emitted submission ≈ **0.852** (v11). If it lands within ±0.002 of 0.852, this is our **compliant floor submission** — pin it, share it, link it.
- [ ] Fallback if the notebook blend ≠ 0.852: keep the per-target weights `V11_W` from v11 (hard-code as the documented fold-safe weights) so the notebook reproduces v11 deterministically.

**Exit criteria for Phase 0:** a pinned, shared, linked notebook that reproduces ≥ 0.850 (v11-equivalent) from official data in one run.

## Phase 1 — v13 small-five specialist iteration (in the same notebook)

Add the v13 stages on top of the Phase-0 notebook (spec: `docs/superpowers/specs/2026-08-07-v13-small-five-specialist-design.md`):

- Leakage-only baseline (CatBoost/LGBM per small target) → ablation CSV.
- Multi-task specialist (PI1M-pretrained GINE trunk, last-2 MP layers unfrozen, 7 heads) with **fold-safe leakage features** + **physics imputations** + physics-residual losses (total weight 0.05–0.1).
- `specialist_no_leakage` head set (embedding-only) for the ~8% non-leaked small-test rows.
- Fold-safe per-target blend over **7 candidates** {specialist, specialist_no_leakage, leakage_only, stack, gnn, v11_blend, physics-imputed}.
- `USE_SPECIALIST = mean_specialist_blend_oof >= mean_v11_blend_oof`; submission uses physics bounds.

- [ ] **Smoke:** `POLYWIN_SMOKE=1` → full v13 pipeline end-to-end on cached experts (validates before Kaggle).
- [ ] **Kaggle full run:** compare per-target OOF vs v11. Per pre-registered criteria: **Strong** = small-five mean +≥0.03 (≥0.876) & no big-three regression > −0.003 → submit v13; **Moderate** = +≥0.01 → submit v13; **Failure** = any target −>0.003 or mean below v11 → ship the Phase-0 (reproduce-v11) notebook.
- [ ] On submit: pin **that exact notebook version**, share with hosts, put the notebook link in the description.
